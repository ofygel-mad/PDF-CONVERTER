# PDF-CONVERTER — правила интерфейса

## Индикаторы состояния

Не кодировать состояние цветной точкой или кружком. Состояние показывать через
то, что уже есть на экране: саму подпись, её вес, положение, движение.

Цвет — только для отказа, никогда для «всё хорошо». Постоянно горящий зелёный —
это шум, который перестают замечать ровно к моменту, когда он должен был
напугать.

Почему правило записано отдельной строкой: цветная точка — дефолт генерации, а
не решение. Она всплывает первой, потому что это самая частая форма статуса в
чужих продуктах и самый безопасный элемент для того, кто не видит отрендеренную
страницу: 6px круг не переполнит контейнер, не потребует ассета и отработает в
обеих темах. Дефолт перебивается только записанным правилом.

Образец применения — `src/components/bbc-dashboard/live-pulse.tsx`: связь с
Google Sheets показана трассой, которая сдвигается на один удар за один успешный
опрос. В покое она графитовая. Цвет появляется только на отказе, движение
означает «данные пришли» и ничего больше.

## Ловушка каскада: утилиты Tailwind против классов globals.css

`@import "tailwindcss"` кладёт утилиты в `@layer utilities`, а правила
`globals.css` не в слое вовсе. По каскаду **неслоёный стиль бьёт любой слой** —
специфичность и порядок не важны.

Отсюда правило: **`hidden` / `sm:hidden` / `sm:flex` не работают на элементе,
у которого есть класс из `globals.css`, задающий `display`** (`.btn-ghost`,
`.logo-badge`, `.bbc-tabbar`, `.badge`, `.bbc-mrow` и прочие). Утилита не
применится, и никакой ошибки не будет — экран просто окажется неправильным.

Прятать такие элементы только через `.only-mobile` / `.only-desktop` из
`globals.css`. Это стоило трёх дефектов на проде: нижний таб-бар дублировал
верхнюю ленту вкладок на десктопе, значок логотипа обрезал заголовок в шапке
телефона, кнопки «Назад» и «Действия» показывались на чужих экранах.

## Проверять правки интерфейса в браузере

Сборка говорит «скомпилировалось», а не «выглядит правильно» — все три дефекта
выше проходили сборку, типы и линтер. Playwright ставится в отдельную папку
(не в зависимости проекта), поднимается `npm run build` + `npm run start`, и
видимость проверяется через `getComputedStyle` на 1440 / 800 / 390 px, а не на
глаз по одному скриншоту.
