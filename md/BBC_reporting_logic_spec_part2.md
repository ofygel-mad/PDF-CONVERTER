# BBC Consulting — Аналитический слой (Часть 2, продолжение)

Продолжение `BBC_reporting_logic_spec.md` (Часть 1). Часть 1 не меняется — это отдельный документ поверх утверждённой логики ДДС/ОПиУ/Баланса. Часть 2 описывает аналитические сводки, которые нужно построить поверх того же массива данных.

## 1. Статус данных на момент составления

- **Собрано / есть шаблон:** отчёт по отделу продаж (готовый сформированный шаблон).
- **В процессе сбора:** данные по сотрудникам (не консолидированы, но сбор идёт быстро); данные по арендным объектам (склады, парковки, помещения под сдачу); маркетинговые расходы (интеграция с Bitrix / Google Таблицами планируется).
- **Не начато:** балансовый список активов (движимое/недвижимое имущество).

## 2. Аналитика по дебиторке

- Свод дебиторской задолженности (опирается на дебиторку из Баланса, см. Часть 1, п. 5).

## 3. Аналитика по клиентам

- Разрез по клиентам поверх Реестра продаж и Журнала операций.

## 4. Аналитика по сотрудникам и отделам

- Аналитика по сотрудникам.
- Эффективность каждого отдела (4 направления: налоговый, бухгалтерский, юридический, HR).
- Эффективность каждого сотрудника.
- Чистая прибыль по каждому отделу.
- Данные по сотрудникам нужно собрать и консолидировать (в процессе).

## 5. Платёжный календарь — 2–3 версии

- **Договорной календарь** — план, основан на датах заключения договоров.
- **Статистический календарь** — основан на статистике фактических оплат прошлых периодов, с учётом того, что клиенты могут оплачивать с опозданием после выставления счёта.
- **Предиктивный календарь** — прогнозирует поведение конкретного клиента на основе его прошлой статистики оплат (опаздывает/платит вовремя).

## 6. Эффективность затрат времени и ценообразование

- Тайм-трекинг: сколько времени сотрудник тратит на каждого своего клиента.
- На основе этого — эффективность каждого сотрудника исходя из его нагрузки.
- Ценообразование: плановый/прогнозный вариант повышения (реже — понижения) цен для клиентов на основе затраченного времени.

## 7. Аналитика по разовым услугам

- Скорость выполнения работ (сколько часов ушло на исполнение обязательств).
- Насколько растянута оплата по периодам после оказания услуги.
- Цель: понять целесообразность оказания разовых услуг как направления.

## 8. Активы и капитал

- Балансовый список активов: движимое и недвижимое имущество.
- Общий баланс: сколько капитала, потенциальный прирост капитала, как эффективно им распоряжаться.
- Арендные объекты (склады, парковки, помещения), которые сдаются — данные ещё не сведены, в процессе сбора.

## 9. Продажи и маркетинг

- Уже есть готовый шаблон отчёта по отделу продаж.
- Планируется интеграция с Bitrix и/или Google Таблицами для анализа маркетингового бюджета: расходы на маркетинг и эффективность маркетинга. Данные пока не собраны до конца.

## 10. KPI и бонусы

- Аналитика для определения, какому отделу и какому сотруднику можно выплачивать бонусы.
- Построение потенциального KPI на уровне отдела и на уровне сотрудника.
- Цель — повысить мотивацию команды и топ-менеджеров к улучшению процессов.

## 11. Открытые вопросы / зависимости

- Данные по сотрудникам, по арендным объектам и по маркетингу ещё не консолидированы — блоки 4 (частично), 8 (арендные объекты) и 9 (маркетинг) зависят от их сбора.
- Балансовый список активов (п. 8) пока не начат.
- Связь с интеграциями (Bitrix / Google Таблицы) для маркетингового блока не определена окончательно.
