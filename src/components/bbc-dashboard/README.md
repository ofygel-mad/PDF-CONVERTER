# BBC Dashboard — frontend module

Страница `/bbc-dashboard` — управленческий отчёт по сводной таблице BBC в Google
Sheets, за авторизацией. Вся вёрстка и логика — внутри `src/components/bbc-dashboard/`.

## Файлы

| Файл | Назначение |
| --- | --- |
| `bbc-dashboard-client.tsx` | Оболочка: шапка, навигация по блокам, live-индикатор. |
| `use-dataset.ts` | Загрузка один раз, мгновенная клиентская фильтрация, состояние фильтров и 4 режимов в URL. |
| `use-live.ts` | Опрос `/bbc/revision` раз в 5 с, пауза на скрытой вкладке, отступ при потере связи. |
| `controls.tsx` | Пресеты, переключатели режимов, панель фильтров, чипы полноты. |
| `charts.tsx` | Инлайн-SVG на токенах: мост, столбцы циклов, спарклайн, хитмап, донат. |
| `format.ts` | Деньги, проценты, даты, русские склонения. |
| `api.ts` | Единственная точка обращения к бэкенду (`/api/backend/api/v1/bbc/*`). |
| `types.ts` | Типы — зеркало `backend/app/bbc/schemas.py`. |
| `icon.tsx` | Иконки модуля (специально не в общем `components/icons.tsx`). |
| `command-palette.tsx` | ⌘K: разделы, режимы, сохранённые виды, клиенты, отделы, сотрудники. |
| `saved-views.ts` | Именованные связки «блок + режим + фильтры» в localStorage (`useSyncExternalStore`). |
| `access/` | Экран входа, личный кабинет, ссылки по отделам. |
| `blocks/` | Восемь блоков интерфейса. |

## Блоки

`receivables` · `reports` · `analytics` · `journal` · `calendar` · `sales` ·
`warnings` · `roadmap`.

Навигация показывает только те, что разрешает область видимости из `/bbc/me`.
Это **оформление, а не граница безопасности**: данные уже отфильтрованы на
сервере, скрытая вкладка ничего не защищает сама по себе.

`roadmap` намеренно показывает, каких данных не хватает, вместо пустого экрана —
то же правило честности, что и чипы полноты.

Печатная таблица стилей прячет навигацию и фильтры и повторяет шапку таблиц на
страницах.

## Признание выручки

Бэкенд предвычисляет раскладку по всем 9 режимам построчно, поэтому фронтенд
**не повторяет бухгалтерскую логику** — он фильтрует строки и складывает нужную
раскладку. Правила живут в Python в одном месте и покрыты тестами.

## Движение

Motion-токены (`--dur-*`, `--ease-*`) и классы `bbc-*` — в
[globals.css](../../app/globals.css). Анимируются только `transform` и `opacity`;
при `prefers-reduced-motion` длительности схлопываются в ноль на уровне токенов,
поэтому компонентам не нужны ветвления.

## Точки соприкосновения с остальным проектом

Ровно одна: плитка «BBC Dashboard» на странице «Сервисы» —
[services-client.tsx](../services/services-client.tsx), импорт `BbcDashboardIcon`
и элемент `TILES` с `href: "/bbc-dashboard"`, оба помечены комментарием
`BBC Dashboard (removable module)`.

Запросы идут через существующий прокси `src/app/api/backend/[...path]/route.ts` —
свои API-роуты на фронте не заводим.

## Как удалить фичу целиком

1. Удалить `src/components/bbc-dashboard/` и `src/app/bbc-dashboard/`.
2. Убрать импорт и элемент `TILES` с пометкой `BBC Dashboard (removable module)`
   в `src/components/services/services-client.tsx`.
3. Убрать блок `BBC Dashboard (removable module)` из `src/app/globals.css`.
4. Бэкенд: см. `backend/app/bbc/README.md`.
